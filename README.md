# Naman Pal – Personal Portfolio Website

Personal portfolio website for **Naman Pal**, Third-Year BTech Computer Science and Engineering student at Galgotias University (Batch 2024–2028).

Designed with a clean, minimal, and professional developer-first aesthetic featuring readable typography, comfortable spacing, subtle blue accents, and a responsive layout without heavy frameworks, artificial percentage bars, or unnecessary animations.

## 🛠️ Built With

- **HTML5** – Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3** – Custom properties, CSS Flexbox and Grid, fully responsive layout.
- **JavaScript (Vanilla)** – Lightweight interactions (header scroll, mobile drawer toggle, active link observer, mailto client draft generator). Zero dependencies.

## 🚀 Local Development

Open `index.html` in any modern web browser or serve via a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```
